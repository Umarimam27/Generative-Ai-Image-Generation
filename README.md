# Generative-Ai-Image-Generation
This project implements text-to-image generation using VQGAN for decoding and CLIP for text-image alignment. Includes model loading, configuration handling, prompt encoding, and an optimization loop for producing high-quality AI-generated visuals.
VQGAN + CLIP — Text-to-Image Generative AI

Create AI-generated images from text prompts using the powerful combination of VQGAN (Vector Quantized Generative Adversarial Network) and CLIP (Contrastive Language–Image Pretraining).
This project implements model loading, CLIP-based guidance, cutouts, augmentation, and an iterative optimization loop for high-quality visual synthesis.

🚀 Features
🧠 CLIP-based text understanding
🎨 VQGAN image synthesis
🔄 Full optimization loop (cutouts, augmentations, LR scheduling)
⚙️ Supports custom prompts
💾 Load pre-trained VQGAN checkpoints
🖼️ Save intermediate frames
📦 Clean, modular code structure
